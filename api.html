type Fiber struct
    with NoCopy
A fiber is a stackful coroutine: a function call that runs on its own stack and can be suspended at any call depth with `suspend`. It is created with `fiber f(args)` and advanced with `resume`. A fiber carries no value. Use a generator to produce values.
fn Fiber :: wait_ready() -> bool
Waits until a future that a suspended fiber of this thread awaits is done, and returns `true`. Returns `false` at once when no fiber awaits a future. A scheduler loop calls it when a round of `resume` calls made no progress. Futures of spawned threads are waited for like `await` does. When only the host can complete the futures, the eval is suspended and all of them are pending (see `cl_vm_pending_futures`). Inside a fiber, that fiber is suspended until a future is done that one of its own fibers awaits: a fiber that it resumed last or asked `waiting()` about last, or a fiber of one of those. It returns `false` at once when none of them awaits a future.
fn (&Fiber) @deinit()
fn (&Fiber) cancel() -> bool
Ends a fiber that is not done without running the rest of its function. Every call that the fiber is in returns at once, from the innermost one out, and the values that the calls own are destructed as at a `return`. A fiber that was never resumed is ended without the call and its arguments are released. A `@deinit` that the unwinding calls runs, and when it stops at a `suspend` or an `await` it ends there the same way. Returns whether the fiber is done afterwards. A fiber that is running is not cancelled.
fn (&Fiber) resume() -> FiberStatus
Runs the fiber until it suspends or its function returns. Returns `.suspended` or `.done`. Resuming a fiber that is done returns `.done`.
fn (&Fiber) status() -> FiberStatus
fn (&Fiber) waiting() -> bool
Whether the fiber is suspended at an `await` or a `Future.wait_any` whose future is not done, or in a `Fiber.wait_ready` while none of its own fibers can go on. A `resume` of such a fiber returns `.suspended` at once.

A scope that is destructed joins its fibers first, so a fiber of a scope never runs after the block that holds the scope. Runs the fibers until all of them are done. A fiber that stops at `suspend` gives the others a turn. When every fiber waits for a future, the scope waits like `Fiber.wait_ready`. Returns the first error that a fiber returned. More fibers can be started after a `join`.

type Cmd struct
A command: a program with its arguments, or several that are joined by pipes, and where and how they run. A `Cmd` is a value. Nothing starts until `run`, `read` or `run_status` is called, and it can be run again. There is no shell. An argument reaches the program as it is, with its spaces, quotes and `$`, so text from outside can not turn into more arguments or another command. A pipe, a working directory, an environment variable, a file for a stream and a time limit are set with methods instead of shell syntax. Sample usage: ```cy use os branch := os.cmd({'git', 'rev-parse', '--abbrev-ref', 'HEAD'}).read()!.trim() top := os.cmd({'du', '-sk', dir}).pipe(os.cmd({'sort', '-rn'})).read()! os.cmd({'make', 'test'}).dir('build').env('CI', '1').stdout_file('build.log').run()! res := os.cmd({'grep', '-c', 'TODO'}).stdin(text).timeout_ms(5000).run_status()! if res.code != 0: eprint(res.err) ```
fn (&Cmd) dir(path str) -> Cmd
Returns this command with `path` as the working directory of every stage it has so far.
fn (&Cmd) env(name str, value str) -> Cmd
Returns this command with the environment variable `name` set to `value` for every stage it has so far. The other variables are those of this process when the command runs.
fn (&Cmd) pipe(next Cmd) -> Cmd
Returns this command with its stdout joined to the stdin of `next`. The result runs both at once. It succeeds when both do. A stage that is stopped because the next one closed its input (as `head` does) counts as a success. The stdin of the result is that of this command and its stdout is that of `next`: text or a file that `stdin` or `stdin_file` gave to `next` is not used, since the stdin of `next` is the pipe, and neither is a file that `stdout_file` gave to this command. The time limit is the shorter one of the two.
fn (&Cmd) read() -> !str
Runs the command, waits for it and returns what its last stage wrote to stdout. stderr is that of this process. Without `stdin` or `stdin_file`, the first stage reads an empty input. Returns the errors of `run`, `error.TooBig` when the output is over 10 MiB, and `error.InvalidArgument` when `stdout_file` or `stdout_append` sent the output to a file.
fn (&Cmd) run() -> !void
Runs the command and waits for it. Its stdout and stderr are those of this process, and so is its stdin unless `stdin` or `stdin_file` gave it one, or a method gave it a file. Returns `error.ExitStatus` when a stage ends with an exit code other than 0 or is stopped by a signal, `error.TimedOut` when the time limit passed, and `error.NotFound`, `error.PermissionDenied` and the like when a program can not be started or a file can not be opened. When the host asks the VM to stop (`cl_vm_interrupt`), the stages are stopped and so is the VM.
fn (&Cmd) run_status() -> !ExecResult
Runs the command, waits for it and returns the stdout of its last stage, the stderr of all stages and the exit code. An exit code other than 0 is not an error here: `code` is that of the last stage that failed, and 128 plus the signal number for a stage that a signal stopped. Without `stdin` or `stdin_file`, the first stage reads an empty input. A stream that goes to a file is not in the result. Returns an error only when a program can not be started or a file can not be opened (`error.NotFound` and the like), when the time limit passed (`error.TimedOut`), or when stdout or stderr is over 10 MiB (`error.TooBig`).
fn (&Cmd) start() -> !Process
Starts the command and returns it while it runs, to read the stdout of its last stage a line at a time. stderr is that of this process, and the first stage reads an empty input without `stdin` or `stdin_file`. The time limit of `timeout_ms` counts from here. Returns the errors of a program that can not be started or a file that can not be opened, as `run` does, and `error.InvalidArgument` when `stdout_file` or `stdout_append` sent the output to a file. Sample usage: ```cy p := os.cmd({'ping', '-c', '3', 'localhost'}).start()! while p.read_line()! |line|: print('> ' + line) p.wait()! ```
fn (&Cmd) stderr_append(path str) -> Cmd
Like `stderr_file`, but the output is added to the end of the file.
fn (&Cmd) stderr_file(path str) -> Cmd
Returns this command with the stderr of every stage it has so far written to the file at `path`. The file is created, or emptied when it exists, when the command runs. Stages that name the same file write to it together. `run_status` does not return what goes to the file in `err`.
fn (&Cmd) stdin(text str) -> Cmd
Returns this command with `text` as the stdin of its first stage, in place of a file that `stdin_file` gave.
fn (&Cmd) stdin_file(path str) -> Cmd
Returns this command with the file at `path` as the stdin of its first stage, in place of text that `stdin` gave. The file is opened when the command runs. A relative path is relative to the working directory of this process, not to that of `dir`.
fn (&Cmd) stdout_append(path str) -> Cmd
Like `stdout_file`, but the output is added to the end of the file.
fn (&Cmd) stdout_file(path str) -> Cmd
Returns this command with the stdout of its last stage written to the file at `path`. The file is created, or emptied when it exists, when the command runs. A relative path is relative to the working directory of this process. `read` can not be used with it, and `run_status` returns an empty `out`.
fn (&Cmd) timeout_ms(ms int) -> Cmd
Returns this command with a time limit of `ms` milliseconds. When the limit passes before the command ends, its stages are stopped (`SIGKILL`, `TerminateProcess`) and the method that ran it returns `error.TimedOut`. The programs that a stage started itself are not stopped. A limit that is not over 0 is `error.InvalidArgument` when the command runs.

fn base(p str) -> str
Returns the last part of the path. Trailing `/` are ignored: `base('a/b/')` is `'b'`. `base('/')` is `'/'` and `base('')` is `'.'`.
fn dir(p str) -> str
Returns the path without its last part, normalized. Trailing `/` are ignored: `dir('a/b/')` is `'a'`. A path with no `/` gives `'.'`, and `dir('/a')` and `dir('/')` give `'/'`.
fn ext(p str) -> str
Returns the extension of the last part, from its last `.`: `ext('a/b.tar.gz')` is `'.gz'`. A name without a `.` and a name that only starts with one (`'.bashrc'`) give `''`.

fn join(a str, b str) -> str
Joins two paths with `/` and normalizes the result. An empty part is skipped, and a part that starts with `/` does not drop the parts before it: `join('a', '/b')` is `'a/b'`. Joining only empty parts gives `''`.

fn normalize(p str) -> str
Returns the shortest path that names the same place, by reading the string only: it removes empty and `.` parts, removes a `..` together with the part before it, and removes a trailing `/`. A `..` at the start of a relative path stays, and a `..` right after the root is removed (`'/..'` is `'/'`). An empty path gives `'.'`.
