# Cyber 0.4.1

릴리스일 2026-10-29. 태그 `0.4.1` → `286377a1`.

soomtong/cyber fork의 첫 릴리스다. upstream(fubark/cyber)의 마지막 커밋 `c853fcc2`(2025-12-21) 위에
Zig 0.17 이식과 fork용 릴리스 · 설치 경로를 올렸다. 언어 기능과 표준 라이브러리는 upstream과 같다.

## 설치

```bash
curl -fsSL https://raw.githubusercontent.com/soomtong/cyber/master/install.sh | bash -s 0.4.1
```

릴리스 번들은 `cyber` 실행 파일과 표준 모듈 `src/`로 이루어진다. 둘을 같은 디렉터리에 둬야 한다.

## Zig 0.17로 이식

upstream은 Zig 0.15 기준이다. 다섯 단계(ZU-M1 ~ ZU-M5)로 Zig 0.17에 맞췄다.

- Zig 0.16의 `std.Io` 모델로 옮기고, `Value`를 extern union으로 바꾸고, Windows `kernel32` 바인딩을 직접 둠(`d64bcde5`).
- Zig 0.17로 올리고, C 헤더를 빌드 중에 번역하고, 표준 라이브러리 레이아웃 변경을 반영(`7e5db56d`).
- 0.17에서 deprecated된 API 교체(`5735bed0`), `stdx.io`에 실제 allocator와 환경 변수 전달(`84d10b39`).
- Windows 환경 변수를 WTF-8로 읽음, `ListWriter`가 한 번에 포맷함, translate-c 결과 공유(`ee12d0b6`).

## 플랫폼별 수정

- Linux x86_64: AVX2 바이트 조회 표를 배열로 만든 뒤 벡터로 읽게 고쳐 교차 빌드 오류 해결(`d303e59f`).
- wasm32: C ABI로 `Value` 비트를 넘기고 `ZVM` padding을 맞춤(`187f4ee6`).
- macOS x86_64: `stat` · `fstat`를 `$INODE64` 심볼에 바인딩해 파일 정보가 맞게 나옴(`90f87ba2`).
- Windows MSVC: 기본 할당자를 libc `malloc`으로(mimalloc 헤더를 translate-c가 처리하지 못함, `8715e1b0`).

## 릴리스와 설치

- `install.sh`가 soomtong/cyber 릴리스를 받음. `CYBER_REPO`로 다른 저장소를 지정할 수 있음(`dfb4b6eb`).
- 번들에 표준 모듈 `src/`를 함께 넣고, `/usr/local/lib/cyber`에 설치한 뒤 `cyber`를 심링크(`b4d2db54`).
- 버전 태그를 push하면 CI가 릴리스를 만듦(`6db63e13`, `5d73e576`). 워크플로를 현재 러너 · 액션으로 갱신(`0bc3a825`).
- 빌드 · 테스트 · 문서 사이트 태스크를 `Taskfile.yml`로 정리(`3815c4c0`).

## 에셋

macOS arm64 · x64, Linux x64, SELinux x64, Windows x64 CLI 번들, WASI `cyber-wasi.wasm`, 플랫폼별 `libcyber`
정적 라이브러리, 문서(`docs.html` · `docs.md` · `api.html`). 모두 14개.

## 알려진 문제

- `-Doptimize=ReleaseFast` · `ReleaseSmall`로 빌드한 CLI가 hello world에서도 세그폴트한다(릴리스 번들은
  `ReleaseSafe`라 영향 없음). 0.4.2에서 고침.
- 인자 없이 `cyber`를 실행하면 REPL이 시작하자마자 "Import path does not exist: `main`"으로 끝난다. 0.4.2에서 고침.
