# Cyber 0.4.2

릴리스일 2026-11-01. 태그 `0.4.2` → `e6401ce7`, 빌드 `build-601-e6401ce`.

0.4.1 이후의 버그 수정, 임베딩 API 확장, 성능 개선을 담았다.

## 설치

```bash
curl -fsSL https://raw.githubusercontent.com/soomtong/cyber/master/install.sh | bash -s 0.4.2
cyber version   # Cyber 0.4.2 build-601-e6401ce
```

## 버그 수정

- 지역 변수를 반환하면 복사해서 `@deinit`이 반환 시점과 호출자에서 두 번 불렸다. 이제 move한다(`eb060d5e`).
- 컴파일 타임 평가에서 for · switch 결과가 초기화되지 않아, 0회 도는 루프가 쓰레기 값을 "반환함"으로 읽었다.
  두 번째 이후 VM에서 인자 없는 `spawn(f, {})`가 ReleaseSafe에서 죽던 원인이다. 루프 안 `return`이 다음 반복에
  덮이던 문제도 고쳤다(`87d4c3ed`).
- 바이트코드의 48비트 피연산자를 8바이트로 써서 버퍼 끝 뒤를 덮어 힙이 손상되던 문제(`c4e443ef`).
- `Slice.append`가 버퍼를 공유하는 빠른 경로에서, 받는 쪽 slice를 남기면 관리 원소가 새던 문제. 버퍼에 초기화된
  원소 수를 기록한다(`8eb4a901`, `718b4d70`, `b8f4efeb`).
- `FutureResolver.complete`가 값을 복사만 하고 해제하지 않아 새던 문제(`d2245290`).
- 호스트 함수가 소유한 `str` 매개변수를 해제하지 않던 문제, `os.exec` 인자는 빌리도록 변경(`c755c23f`).
- `single_run` 종료 시 main 블록의 raw 버퍼와 힙을 정리, 제너레이터를 struct 그대로 boxing(`3f7e3281`, `47955405`).
- `-Doptimize=ReleaseFast` · `ReleaseSmall` CLI의 세그폴트: `ZHeap` · `ZVM` padding을 빌드 모드별로 맞추고
  `resolveFuncSig` · `FuncSym.firstFuncSig`의 초기화 누락을 고침(`ce521d5d`, `b48a1b69`, `894e0117`).
- `-Dffi=false` 빌드에서 extern 호출이 프로세스를 죽이지 않고 panic으로 끝남(`51fcdb92`).
- 인자 없이 `cyber`를 실행하면 REPL이 시작하지 못하던 문제(`eb060d5e`).

## 임베딩 API (libcyber)

- `cl_vm_interrupt`(다른 스레드에서 실행 중인 eval 중단) · `cl_vm_set_fuel`(검사점 횟수 제한). 결과는
  `CL_ERROR_INTERRUPT`이고 VM은 다시 쓸 수 있다. spawn된 스레드에도 적용된다(`f21993e2`, `26b8d753`).
- `persist_main`으로 반복 eval할 때 main의 지역 변수가 다음 eval로 넘어가고, 같은 이름을 다시 선언할 수 있다(`e541090a`).
- 같은 VM에서 eval을 반복할 때의 오류 수정, 호스트 도구 바인딩 예제 `examples/libcyber/host_tool.c`(`c89474e9`).
- 호스트 함수가 소유한 slice 매개변수를 해제하는 `cl_slice_deinit`(`1490366c`).

## 성능

`src/test/bench/`의 벤치를 M1 Max에서 hyperfine으로 잰 wall time(시작 시간 포함, 10회 평균)이다. 두 빌드 모두
ReleaseSafe 릴리스 구성이다. 0.4.1과 이전 0.4.2 빌드 사이에는 성능 변경이 없다.

| 벤치 | 이전 0.4.2 (`build-562`) | 현재 0.4.2 (`build-601`) |
|---|---|---|
| `for/for.cy` (배열 100만 append · 순회) | 101.8 ms | 57.6 ms |
| `heap/heap.cy` | 58.3 ms | 38.3 ms |
| `string/index.cy` | 105.5 ms | 80.2 ms |
| `string/index_rare.cy` (첫 바이트가 드문 입력) | 81.2 ms | 55.7 ms |
| `fib/fib.cy` (호출 위주, 비교용) | 32.9 ms | 33.1 ms |

- `str.index`: 128바이트 블록을 첫 바이트 → 첫+끝 바이트 순으로 걸러 후보 블록에서만 비트마스크를 만든다(`1a109cec`).
- 배열 `@index_addr` · `@index` · `@set_index` · `next` · `append`의 내부 보조 함수 호출을 식으로 직접 계산(`9d3df55e`).
- 64비트 정수 상수 연산을 컴파일 시 접고, 포인터 인덱스 주소를 명령 하나(`add_mul_i16`)로, 작은 상수 덧셈을
  `add_i16`으로 내림(`5171b7fa`).

## 변경

- JIT 백엔드(`-jit`, 임베딩 `CL_JIT`)는 지원하지 않는다. 고르면 "The JIT backend is not supported." 컴파일 오류가
  난다. `cyber help`에서 `-jit`를 뺐다. `CL_JIT` enum 값은 ABI 호환을 위해 남긴다(`e6401ce7`).
- 번들에는 각 타깃이 실제로 쓰는 표준 모듈만 넣는다(macOS · Linux 12개, `68f0478a`).
- `install.sh`는 대상 디렉터리에 쓸 수 없을 때만 sudo를 쓰고, `CYBER_BIN`으로 심링크 위치를 바꿀 수 있다(`ba14e80b`).
- C 헤더 번역을 translate-c 패키지로, deprecated된 `DebugAllocator` · `std.unicode.utf8Decode` 교체(`d56e87ce`, `a35e7a97`, `59723369`).
- CI에서 Linux · macOS arm64 · WASI의 ReleaseFast 테스트를 돌린다(`a5682852`).

## 알려진 문제

- REPL에 stdin을 파이프로 넣으면 입력 끝(EOF)에서 정상 종료하지 않고 `panic: EndOfStream`을 낸다. 직접 입력할 때는 영향 없음.
- 배열 루프는 여전히 Lua보다 약 3.6배 느리다. 남은 비용은 메서드 호출 자체라 작은 함수 인라인이 필요하다.
