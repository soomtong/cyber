# Cyber 0.4.3

릴리스일 2026-11-06. 태그 `0.4.3` → `a26645f1`, 빌드 `build-668-a26645f`.

0.4.2 이후의 제너레이터 · REPL · 메모리 버그 수정, REPL과 `print` 출력 개선, 바이트코드 인라인과 레지스터 접근 개선에 따른
성능 향상을 담았다.

## 설치

```bash
curl -fsSL https://raw.githubusercontent.com/soomtong/cyber/master/install.sh | bash -s 0.4.3
cyber version   # Cyber 0.4.3 build-668-a26645f
```

## 버그 수정

- 제너레이터 본문의 지역 변수가 `yield`를 넘어 보존되지 않았다(`i := 10; yield i; i += 1; yield i`가 10, 11, 11). 이제 `ret_gen`이
  프레임 전체를 저장하고 `yield`가 되저장하며, 재개 시 스택을 검사하고 키운다. 관리 타입 지역(`str` 등)이 있을 때의 세그폴트도 같은
  원인이었다(`a2236c78`, `3422e526`, `5d78b14f`, `07e66fad`).
- 제너레이터 안에서 panic이 나면 언와인드가 죽어 호스트 프로세스가 abort했다. `meta.stack_trace()`가 바깥 프레임 두 개를 지우고
  이름 · 버퍼를 새던 것도 고쳤다(`c8d85d6f`, `0ea223d9`).
- `#[generator]` 밖에서 `yield`를 쓰면 컴파일러가 세그폴트했다. 이제 컴파일 오류다(`3aa5b400`).
- `*(as[Ptr[T]] p)[i]`처럼 포인터를 역참조해 인덱싱하면 원소를 임시에 복사한 뒤 해제해 `Map[str]` 키가 이중 해제됐다.
  역참조는 항상 주소를 가진다(`d99a8aa9`).
- `sp := [&]int{1, 2, 3}`이 바이트코드 생성에서 panic했다(`c67c3e65`).
- REPL 맨 위에 빌림 타입 지역(`r := &x`)을 두면 다음 입력에서 스택이 재할당된 뒤 해제된 메모리를 읽었다. 맨 위 빌림 지역은 컴파일
  오류로 막는다. 블록 안은 허용(`7e7268b0`).
- `for`가 `^T` iterable을 retain하지 않아 이중 해제됐고, REPL의 choice 결과가 샜다(`eb8134b3`, `46faf101`).
- 템플릿 `type X const`가 기존 타입을 반환하면 그 타입의 이름이 덮어써졌다(`ab8163bc`).
- `HashMap.set`이 값을 덮어쓸 때 `len` · 빈 슬롯 수가 어긋났다(`5ded4ef2`).
- x86_64 AVX2 빌드의 `str.index`가 하위 니블이 같은 바이트 집합에서 틀린 결과를 냈다(`a1b2a75f`).
- Linux CLI의 rpath에 빈 항목이 있어 현재 디렉터리의 공유 라이브러리가 시스템 경로보다 먼저 잡혔다. `DT_RUNPATH`는 `$ORIGIN`만이다
  (`1a1bdf60`).
- 정적 musl 빌드가 자기 자신을 `dlopen`하지 못해 죽었다. libc `dlopen`을 쓰고 musl에서는 `ffi` 기본값을 끈다(`ab626361`).
- wasm32에서 `Span` 포인터의 패딩 바이트가 호스트 함수를 panic시켰다(`6cb22fff`).
- VM의 `JUMP_T` 명령이 거짓일 때 점프하도록 뒤집혀 있었다(쓰는 곳이 없어 드러나지 않았음). 덤프의 `is_zero` 피연산자와 `and_` 등
  빈 덤프, 뒤로 가는 `jump` 표시도 고쳤다(`38272a0c`, `15a85a9e`, `7563e3b4`).

## REPL과 출력

- REPL이 마지막 맨 표현식의 값을 타입과 함께 보여준다. option · enum · choice · struct · Slice · Array · Vector · Map · `^T`를 펼치고
  (깊이 3 · 10개 한도), `[&]T`는 원소 목록으로, `&T`는 `&값`으로 표시한다(`f81693f3`, `4e3af453`, `46faf101`, `c67c3e65`).
- `#[...]` 속성 줄을 다음 선언과 묶어 컴파일한다(`af00c105`).
- `print`와 문자열 보간이 struct를 `Point{x=1, y=2}`, choice를 `Shape.circle(5)`, Slice · Vector를 `{1, 2}`로 펼친다. 이전에는
  타입 이름이나 `Shape@circle{}`였다. `dump` · `dump_str`는 같은 값을 한 줄에 필드 · 원소 하나씩 찍는다. `Map` · `Array`는
  빌림으로 `print(&m)` · `dump(&m)`(`6f46a8aa`, `17d61251`, `b106f0cd`).
- 입력 끝(EOF)에서 REPL이 panic하지 않고 끝난다. Windows는 한 줄 읽기 fallback(`a2c586c2`, 0.4.2 마지막 빌드에 포함).

## 언어와 표준 라이브러리

- `for`가 제너레이터와 `^ArrayStore`를 순회한다(`eb8134b3`, `90fafc1f`).
- `str.from_utf8(bytes) -> !str`(`error.Unicode`)와 `str.is_utf8`. `str(bytes)`는 UTF-8을 검증하지 않으므로 외부 입력은
  `from_utf8`로 받는다. 동작하지 않던 `str.decode` 선언은 뺐다(`e4c0347c`).
- 문자열 보간이 네이티브로 한 번에 할당하고 int → str이 포매터를 바로 부른다. `'k%{i}'` 100만 회 298 → 123 ms(`c0dcaeb5`).
- `str` 복사는 `@copy` 호출 대신 `copy_str` 명령 하나(`72f4ecef`).
- 현재 문법의 tree-sitter 문법을 `exts/`에 추가(`8bdeed2c`).

## 성능

`src/test/bench/`의 벤치를 M1 Max에서 두 바이너리를 번갈아 hyperfine으로 잰 wall time(시작 시간 포함, 10회 평균). 둘 다
ReleaseSafe 릴리스 구성이다.

| 벤치 | 0.4.2 (`build-605`) | 0.4.3 |
|---|---|---|
| `for/for.cy` (배열 100만 append · 순회) | 57.0 ms | 37.0 ms |
| `heap/heap.cy` | 37.6 ms | 30.0 ms |
| `fib/fib.cy` (호출 위주) | 32.9 ms | 28.9 ms |
| `fiber/fiber.cy` (제너레이터) | 41.5 ms | 37.9 ms |
| `alloc/alloc.cy` (`Map[str]` 채우기) | 5.11 s | 0.62 s |
| `string/index.cy` · `index_rare.cy` | 77.7 · 53.7 ms | 76.9 · 53.8 ms |

- 바이트코드 인라인: panic할 수 없는 작은 leaf 함수부터 시작해 본문 안 호출 · 루프 · 중첩(깊이 3) · `#[inline]` 속성을 허용하고,
  인라인 구간을 스택 트레이스에서 callee · caller 두 프레임으로 펼친다. 호출 지점 규칙(`never` callee · 오류 경로 제외, 큰 본문은
  루프 안이나 `#[inline]`만)으로 바이트코드 증가를 +27%로 묶었다. 재귀 함수의 자기 호출은 한 단계만 펼친다
  (`d8ddbe44`, `b40531a1`, `8fbc0f21`, `abdd967e`, `2fe9fb54`, `1d3b8e72`, `7563e3b4`, `fe8637fc`, `bb75979d`, `2fb52a9d`).
- 레지스터에 있는 레코드의 8바이트 정렬 필드를 주소 없이 `지역 + offset/8` 레지스터로 읽고 쓴다. `init`은 목적지 레지스터에 바로
  쓰고, 인라인 호출의 `&지역` 인자는 callee 매개변수를 그 지역에 묶는다. 인라인 반환과 선언 지역을 목적지로 하는 `init`도
  필드를 바로 쓴다(`38272a0c`, `58ba5c26`, `db9f636d`).
- `Array.cap()`의 상수 마스크를 `and_64` 명령 하나로(`132d5504`). `Vector` 인덱스 경계 비교를 직접(`6b7a1d72`).
- `Map[str]`: Wyhash를 Zig로 옮겨 `#[bind]`, 크기 조정은 원소 이동만, 구조체 해제는 관리 필드만, 핫 경로 호출 제거
  (`27d63c3b`, `c307197b`, `72f4ecef`, `5ded4ef2`).
- 도달 불가 블록 끝의 지역 해제를 내지 않아 바이트코드 −6%(`7563e3b4`).

## 변경

- 복사-패치 JIT 잔재(`src/jit/`, `#[jit]` 속성, `enter_jit` 명령, `-Djit`)를 삭제했다. `-jit`와 `CL_JIT`은 그대로 "The JIT backend
  is not supported." 오류로 거절한다. `#[jit]`는 이제 "Unknown attribute." 파스 오류(`b4145397`).
- lib-test가 모든 pub 선언을 참조해 죽은 코드가 빌드를 깨게 했고, 그렇게 드러난 `fiber.zig` · `llvm_gen.zig` · `dce.zig` 등 죽은
  코드를 지웠다(`bc169c5b`, `a7b51ceb`, `32fab0fa`).
- musl 정적 타깃의 `-Dffi` 기본값이 꺼진다(`ab626361`).
- `docs/study/`에 소스 학습 가이드 10편, 동시성 모델 안내, 제너레이터 · fiber 병행 설계 리뷰, 약어 안내를 추가했다. 학습 중 발견한
  이슈 표(`docs/study/10-findings-register.md`)에 이번 릴리스에서 고친 항목의 커밋을 적었다(`5ba4d831`, `c5c156e8`, `1cd98cf9`,
  `d54960c9`, `28f0436b`).

## 알려진 문제

`docs/study/10-findings-register.md`에 전체 목록이 있다. 스크립트에서 바로 닿는 것만 적는다.

- `[]T.index(needle)`가 자기 자신을 불러 끝나지 않는다(`contains`는 정상). `int.parse('-5')`가 `error.InvalidCharacter`,
  `int.parse('')`는 `0`. `Map.keys()`는 컴파일 오류.
- 64비트를 넘는 정수 리터럴이 오류 없이 wrap된다. 컴파일 타임 평가(`const x = f()`)가 복합 대입(`+=`)을 버린다.
- `g := math.sqrt; g(16.0)`처럼 호스트 함수를 값으로 부르면 세그폴트. 스택 성장에 상한이 없다.
- 배열 루프는 Lua보다 약 2.3배 느리다.
